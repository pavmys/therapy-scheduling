# Spec Delta

## Purpose
Доступ до застосунку для тих, хто не має права бачити дані: відвідувач без входу бачить лише сторінку входу, а користувач без ролі — лише повідомлення, що доступу ще немає.

## ADDED Requirements

### Requirement: Відвідувач без входу бачить лише сторінку входу
IF відвідувач не увійшов у застосунок і відкриває за прямим посиланням список клієнтів, картку клієнта чи список утримань, THEN the system SHALL показати лише сторінку входу без жодних даних клієнтів чи утримань і не змінювати жодної картки.

#### Scenario: AC-CARD-07 Пряме посилання без входу
- **GIVEN** користувач не увійшов у застосунок
- **WHEN** він відкриває за прямим посиланням список клієнтів, картку client6 або список утримань
- **THEN** він бачить лише сторінку входу, жодних даних клієнтів чи утримань не показано
- **AND** жодна картка не змінилася

### Requirement: Користувач без ролі не має доступу до даних
IF користувач увійшов у застосунок, але не має ролі, THEN the system SHALL показувати йому лише повідомлення «Your account has no access yet. Contact an administrator.» без жодних даних клієнтів і не змінювати жодної картки.

#### Scenario: AC-CARD-11 Користувач без ролі
- **GIVEN** користувач newuser1@example.test увійшов, але не має ролі
- **WHEN** він відкриває застосунок або картку client6 за прямим посиланням
- **THEN** він бачить лише повідомлення «Your account has no access yet. Contact an administrator.», і жодних даних клієнтів не показано
- **AND** жодна картка не змінилася
